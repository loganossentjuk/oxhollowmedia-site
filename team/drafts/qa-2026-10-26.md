## Notes (not bugs)
- Low, proposal: `build_print_pages.py` stamps `<lastmod>` with today's date on every print on every run, even when nothing changed. Every rebuild therefore dirties 65 sitemap entries (130-line diff) and tells Google every print changed. Proposed fix: take lastmod from the print's own change (catalog entry date or file mtime), or keep the old value when the page HTML is byte-identical. Google says it uses lastmod only when it is consistently accurate: https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap (cited from prior knowledge; web not re-read this run).
- Test-script false alarms (my errors, fixed in the script): paper buttons sit inside the "framed" panel under frame "No frame", and the lightbox is toggled by the `hidden` attribute, not an `open` class.
- Local `http.server` does not do Cloudflare's extensionless routing, so `/prints/<slug>` returns 404 locally; I tested `/prints/<slug>.html`. Production resolves the extensionless URLs. This run did not check the live site (proxy).
- External requests (Google Fonts etc.) fail in this sandbox with ERR_TUNNEL_CONNECTION_FAILED. Ignored as an environment limit, not a site error.
- Not run: Shopify live variant check (catalog-only), Formspree form submission (not posted to a third party), axe contrast audit (still on the backlog).
