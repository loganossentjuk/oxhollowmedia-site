# Event photo index

Internal reference for the event photos on /events and the gallery's Events filter.
Visitors never see these names. Refer to a photo by its number (for example "swap E19").

- The number is the file prefix: `E19` is `images/portfolio/events/19-*.jpg`/`.webp`, and `data-ref="E19"` in the HTML.
- New photos take the next free number. Don't reuse a retired number.
- Category is `data-sub`: Candids (unposed), Portraits (posed, looking at camera), Atmosphere (wide shots, objects).
